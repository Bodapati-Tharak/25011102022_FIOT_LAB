Documentation Format
Each CAT folder will contain the experiment date, exact experiment and task names from the corresponding evaluation PDF, hardware/platform details, required circuit diagram, core logic or pseudocode, project/source files, and inference. Experiments with multiple tasks will keep those tasks clearly separated within the same CAT folder.

Circuit diagrams and verified source files will be added as each experiment is prepared. Generated build files and user-specific IDE files are excluded using .gitignore.

Status: Repository organization and experiment documentation are in progress.
